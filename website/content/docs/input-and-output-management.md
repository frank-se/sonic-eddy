Wireplumber, and by extension Sonic Eddy, works by routing audio streams, which
makes the integration of audio interfaces with too many inputs and/or outputs
somewhat complicated. Sonic Eddy provides virtual inputs and outputs to manage
pro-audio devices.

Virtual inputs map the devices playback ports to playback nodes, while virtual
outputs map map the devices capture ports to capture nodes.
