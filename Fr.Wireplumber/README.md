# Fr.Wireplumber

.NET bindings for Wireplumber and Pipewire (PipeWire session/policy manager).

⚠️ This package only works on Linux x86_64

It contains native shared libraries (.so) and will fail to restore on Windows and macOS.

Supported runtime: `linux-x64` (glibc)

## Dependencies

- libpipewire 0.3
- wireplumber 0.5
